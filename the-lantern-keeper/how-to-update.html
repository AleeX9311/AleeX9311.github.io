How to update

Journal and Hostinger

The site is an ordinary package of files. There is no database and no build step. The page text is in HTML. Journal entries are in posts.json.

Open the site through its address, or through a local web server. If you open an HTML file directly from a folder, the journal may not load.

A new entry

  1. Open posts.json in a text editor.
  2. Copy one existing entry, including the curly braces.
  3. Change slug (a short name used in the address, with no spaces), title, date in the form 2026-11-25, excerpt, and body.
  4. In body, a blank line separates paragraphs. ## at the start of a paragraph makes a subheading. *word* is italic, and **word** is bold.
  5. Save the file. Leave a comma between entries. The last entry has no comma after it.
{
  "slug": "a-clear-night",
  "title": "A clear night",
  "date": "2026-11-25",
  "excerpt": "One or two sentences for the journal list.",
  "body": "First paragraph.\n\n## A subheading\n\nNext paragraph, with an *italic* word."
}

Upload to Hostinger

  1. In hPanel, open Websites, choose the site, then Files, then File Manager.
  2. Open the public_html folder. If the site should live in a subfolder, create that folder and open it.
  3. Upload all the files from this folder: the HTML files, site.css, site.js, posts.json, and the icon and social image if you want them.
  4. You can send the same package by FTP (for example with FileZilla) into public_html. The host, username, and password are in hPanel under FTP accounts.
  5. Refresh the page in the browser. The new entry shows on the Journal page and on the home page.

Shop buttons and page text

The Bookshop, Amazon, and Barnes & Noble buttons point at example.com. In index.html and book.html, replace those addresses with the real shop links. Edit the paragraphs about the book and the author directly in those HTML files.

The canonical and social links in each page head point at this sample address. When the site has its own domain, replace https://aleex9311.github.io/the-lantern-keeper/ with that domain.
