# Aleks Kmetec

Portfolio of Aleks Kmetec, a web developer in Slovenia (EU).

The live site is [aleex9311.github.io](https://aleex9311.github.io/). GitHub Pages serves the `main` branch from the repository root. `.nojekyll` keeps Pages from running Jekyll, so these static files are published as they are.

## Pages

- `/` — home: services, process, sample work, and contact
- `/the-lantern-keeper/` — sample author site for the fictional novel *The Lantern Keeper*, with a journal in `posts.json` and an English how-to page
- `/linden-table/` — sample bistro site
- `/orchard-desk/` — sample product landing page
- `/quote-bench/` — sample quote comparison tool
- `/credits.html` — Unsplash photograph credits

The four projects are fictional demonstrations. Each project folder can stand on its own.
